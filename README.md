 UBA Banking Website Clone

A responsive front-end clone of the United Bank for Africa (UBA) web portal. 
I built this level 1 project to practice and showcase my skills in building clean user interfaces, 
responsive CSS layouts, and interactive vanilla JavaScript elements.

Live Demo: [View on Netlify](https://ubabankingclone-396600.netlify.app)

 Tech Stack
* **HTML5:** Multi-page routing and semantic structure.
* **CSS3:** Custom styling, Flexbox/Grid, and mobile responsiveness.
* **JavaScript:** Mega-menus, FAQ accordions, and tab functionality.

 Key Pages
* `index.html` - Main Landing Page
* `internetbanking.html` - Animated Login UI
* `FAQS.html` - Interactive Help Center
* `accountopening.html` & `instantselfregistration.html` - Multi-step Form Layouts

⚠️ Disclaimer
This is a front-end clone built strictly for educational and portfolio purposes. 
It is not affiliated with, endorsed by, or connected to the United Bank for Africa (UBA).
There is no backend, database, or real authentication connected to this project. Do not enter real personal or financial data.
